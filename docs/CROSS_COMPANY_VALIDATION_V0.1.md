# 有限跨公司验证协议 V0.1

日期：2026-09-20；对应 #20。用户已批准选一家额外公司的公开报告验证可复用范围与改造成本。当前产品登记与问题能力仍仅支持安克，任何测试成功都不自动扩大产品范围。

## 已锁定的首次验证规则

首选一份非金融 A 股公司季度完整报告，使用法定披露的归母、扣非归母与非经常性损益；优先与安克有不同表格布局、但不需要银行/保险专用财务定义的制造业公司。候选为公牛集团 2026Q1；在找到官方原件之前不填写 URL、摘要、数字或 PASS。不得看过运行结果后改选公司只保留成功样本。

1. 在解析前登记公司、期间、官方来源、PDF SHA-256、锁定代码 SHA 与选取理由。明确它此前是否用于开发；无法证明未见过就不叫盲测。
2. 只调用现有 `parseFinancialReportV06Strict`，保留 PDF 坐标、原始首次输出、错误、耗时和原件摘要；不得先写“正确答案”再调 parser。工具不调用模型，也不进入浏览器正式研究空间。
3. 首次结果保存后，独立从 PDF 原页核查三个指标、本期/同期列、单位、符号、同比及 F-02 桥。人工核查必须标明复核者；助手复核只称助手初审。
4. 区分 `ACQUISITION_FAILED`、`EXECUTION_FAILED`、`UNSUPPORTED_FORMAT`、`RECONCILIATION_FAILED`、`PARSED_REVIEW_PENDING`、`REVIEWED_LIMITED_PASS`。下载失败不能解释成财务假设不成立；parser 放行也不是内容准确的充分证据。
5. 遇到缺支持的列/标签就登记差异及配置或实现成本，保留第一结果。修复若改变财务定义、阈值或研究语义，另述影响；不能套用安克的 A-03、K-07、估值和判断来伪造新公司闭环。

## 当前执行情况

已完成隔离首跑工具 `apps/web/scripts/run-transfer-probe.mjs` 与上述协议。公开检索尚未核实候选报告的官方原件；未拿搜索摘要或别家报告替代。**实际首次跨公司解析未运行**。因此状态为材料获取待完成，不能写成迁移成功或失败。

收到公开原件并核实来源后，以已登记 metadata JSON（`sourceId` 必须以 `XFER-` 开头；`company`、`period`、`url`、`pdfSha256`）运行：

```bash
cd apps/web
node --experimental-strip-types scripts/run-transfer-probe.mjs /absolute/report.pdf /absolute/metadata.json /absolute/new-output-directory
```

输出目录必须不存在，避免覆盖首次结果。归档后填写三指标的“模型/程序原值、独立原文值、页码、单位、判定”表。至少一份新材料可支持“新增单案例有限验证”，不能支持任意公司泛化、收益能力或稳定性结论。跨公司真实问题调用不在本轮六请求批次中。

30 天真实环境跟踪是另一个实验：先写观察协议、时间戳、不可回填的版本记录和资料覆盖，再决定样本。当前不启用交易、定时爬取或自动模型调用。
