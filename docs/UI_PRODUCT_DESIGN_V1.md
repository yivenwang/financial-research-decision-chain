# Beacon｜研灯：整套桌面 UI V1

本次在 `ui/beacon-light-workbench-v01` / PR #28 上集中实现品牌首页与研究任务界面。首页与工作台共享深蓝、青灰和灯塔语言；工作区保持已批准的浅色方向。财务引擎、判断规则、模型提示词、专业关卡和历史记录均不在本次改动范围内。

## 页面与交互

| 页面 | 已实现内容 |
| --- | --- |
| `/` 品牌首页 | 中文品牌主张、原生 SVG 灯塔与可减少动态效果的光束、问题输入与示例、四步研究方法、键盘可操作的案例解读、能力边界 |
| `/workspace` 研究概览 | 当前保存版本、证据审核数量、规则影响节点、待复核关卡、研究路径、后续任务；加载、基线、读取异常分别展示 |
| `/questions` 研究提问 | 首页问题准确传入；既有任务确认、执行、引用、反证、人工审核与导出；补材料链接进入变更页 |
| `/changes` 变更审核 | 统一上传、逐项审核、影响计算、保存版本界面；原始工作流与审阅规则不变 |
| `/evidence` 证据核验 | 左侧选择当前证据，右侧展示来源、位置、方向、片段和 PDF 链接；固定案例单独折叠、明确标注 |
| `/versions` 版本记录 | 统一时间线、快照、Memo、人工修订、导出与回滚弹窗；时间显示固定为北京时间，避免服务器与浏览器时区不一致 |
| `/help` 使用说明 | 研究入口、本机存储、导出、模型访问、缺材料与专业审核边界说明 |

## 视觉规范

- 品牌底色 `#142b3b` / `#173e50`；主操作青色 `#176a73`；工作区背景 `#f4f7f8`；卡片白色；边框 `#dce5e9`。
- 中文内容为主，英文只用于栏目层级和品牌表达。工作台以任务侧栏、页标题、共同状态栏、当前任务、来源细节构成层级。
- 支持、待审核、退回均保留文字和图标，不仅依赖颜色。输入、链接、按钮保留可见焦点；首页案例支持方向键、Home、End 切换；独立弹出层遵循系统减少动画偏好。
- 桌面侧栏在窄屏转为横向导航。核验尺寸为 1440、1366、768、390 像素；窄屏适配不等于独立 Mobile Companion 已交付。
- 首页品牌图为代码原生 SVG，不请求外部图片、字体或数据。系统中文字体可正常显示页面；浏览器截图环境也应安装中文字库。

## 数据与能力边界

1. 当前问题范围仍为安克创新 / S-05 / 2026Q1 / C-04。S-06 只进入独立回归演示。
2. 固定案例、教学合成样例与当前保存的真实 PDF 版本分别标注；不将案例数字补入空研究状态。
3. EG-01 / EG-02 保持待复核；人工身份未鉴证；保存研究版本不等于投资认可或交易。
4. 规则影响节点不是任意版本逐字段差分。PDF 链接是登记来源，不代表服务端已鉴证文件字节。
5. 记录保存在当前浏览器，没有账号同步、团队共享或已实现的反馈后台。
6. 本次无新增付费模型请求；没有合并、部署或修改 `main`。

## 验收与截图

沿用 `npm test`、迁移保护、生产构建、运行检查、真实 S-05 与隔离 S-06 浏览器回归，以及 NOT-LIVE 问题流程。新增 `tests/ui-suite-browser.test.mjs`，在离线教学样例下覆盖七条页面路由、四个视口、问题传递、案例键盘操作、证据选择、弹窗和异常数据保留；不得将其称为真实模型验收。

CI 输出保存在 `apps/web/artifacts-web/`，整套 UI 截图位于 `ui-suite/`。只有对应提交的工作流实际完成后，才能在 PR 中标记通过。本机截图环境缺少中文字体时，必须以具备中文字体的截图复核排版。

本轮新品牌组件与页面通过定向 ESLint。研究提问组件原有的浏览器台账挂载读取触发 `react-hooks/set-state-in-effect`，该初始化机制本轮保持不变；不把定向 lint 表述为整个仓库零告警。
