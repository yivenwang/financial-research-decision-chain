## Repair

V0.6 recognizes primary rows with restated comparison columns:

`current | prior-before-adjustment | prior-after-adjustment | disclosed change`

When a primary metric row contains >=4 numeric tokens, V0.6 uses:
- current = first numeric token
- comparison = penultimate numeric token (adjusted comparison)
- disclosed change = last numeric token

Normal three-token rows retain V0.5 behavior.
