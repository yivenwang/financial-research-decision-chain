以下两期归母/扣非来自任务给定基线；非经常与变动额为独立算术推导，不能称为原文披露的比较值。真实 S-05 浏览器快照另外核验本期披露非经常性损益与桥闭合。

| 扣非归母净利润（给定原值） | 439,558,407.22 | 546,758,896.90 | +107,200,489.68 |

两期分别满足归母 − 非经常 = 扣非；同比满足 `-24,167,015.58 = +107,200,489.68 − 131,367,505.26`。本期非经常为负是水平描述；同比下降的算术贡献是该项从正到负变化，超过扣非增加。不能仅用“本期为负”替代同比归因，不能从算术桥推定已验证的经济原因。比较均为 Q1 对 Q1，研究基准版本不替代上年同期。

## 剩余风险与上线建议

**现在不建议直接部署。** 可提交技术 PR 审查，但尚有生产接入和人工内容复测依赖：

1. 自托管 Node 的 `RESEARCH_RUN_DIRECTORY` 必须为私有、绝对、可写、跨部署/重启保留的目录，位于 checkout/.next 之外；多 worker 必须共享同一文件系统。生产未配置会 fail closed。本轮没有配置生产目录，也没有付费存储服务。
2. 磁盘收据保留研究内容、原输出和失败记录，不能公开静态服务；需要权限、容量监测和备份。没有后台删除/过期清理审计记录；长期容量治理待方案。
3. 文件系统保证同一操作不重复执行，不是 exactly-once provider 事务：provider 已接收而进程未写回时计费/内容未知。断网只读取或手动重发同 key；不确定 claim 应维护者核查，不能删 claim 诱发重试。
4. 同进程跨端点调用槽不是多机器全局额度；Memo 的持久恢复与顺序幂等未实现。部署不应据此宣称全部研究调用都有全局成本控制。
5. 没有真实模型内容验收；语义范围、引用是否支撑具体段落、经济原因与假设边界仍需人工。词法校验不能证明金融语义正确。
6. Reviewer 未复现项的最小补充：问题原文、request/run ID、原始阻断输出、时间/设备/浏览器/操作顺序；上传问题还需文件 SHA、大小/MIME、所选 Source 与错误提示。无需提供密钥或访问码。
7. 原访问窗口已结束；开放新的人工复测窗口是所有者的单独运营决定，本轮不修改。EG-01/EG-02 与跨公司研究能力仍未完成。

- 运维验证私有持久目录的权限、同文件系统跨 worker 占位、磁盘不足 fail closed、备份、跨发布/重启保留；不删除失败 claim。
- 在获准的审验窗口内测试实际 HTTPS 登录、刷新/多 Tab、真实 S-05 上传与页码、原文金额对照、材料审核→保存→Question 计划→确认→执行→Review→编辑→导出→回滚。
- 对三类问题与合理改写逐个人工核对范围判断；比较 unsupported 公司/期间、无材料、坏快照是否各自正确拒绝，不把 OUT_OF_SCOPE 改成成功。
- 对原 Reviewer 两条错误的原始输出核对是模型违规还是校验误拒；只对完整且正确标注/引用的草稿追加审核，保留旧失败。真实调用须另按批准批次/预算执行，无自动重试。
- 执行中双击、刷新、断网、两个 Tab 确认；观察 provider 请求数及服务器状态。重启导致不确定结果时确认禁止自动重发，人工新任务明确可能再计费。
- 对照五条原始金额与两期利润桥，确认“非经常本期负值”和“同比算术贡献”分开，经济原因/会计假设/最终判断保持待复核。
- 人工退回→重新接受→人工修订→新修订 pending→版本保存→回滚；导出前后比较旧快照/AI 原稿及审核事件摘要不变。
- 实机手机与弱网检查 PDF 边界、超时说明、状态按钮、水平溢出与滚动；此项目前未验证。
