## Repairs frozen in V0.4

1. Source metadata is inherited from import context; no concrete Source ID is hard-coded in the parser.
2. PDF parsing preserves geometry and does not flatten the document into a whitespace-stripped regex window.
3. Numeric column boundaries are derived from inter-column geometry, including real CNINFO PDFs where number starts sit left of header text starts.
4. Wrapped label rows are associated with the nearest numeric row on the same primary-table page.
5. Primary-table geometry is not reused across later report pages.
6. Non-recurring P&L total can be located across page boundaries.
7. Required F-02 fields block promotion when incomplete.
8. Currency/share YoY values are reconciled as relative changes.
9. Ratio disclosures such as ROE are reconciled as percentage-point deltas.
10. Any FAIL blocker prevents normal Evidence / Graph Diff / version promotion.
