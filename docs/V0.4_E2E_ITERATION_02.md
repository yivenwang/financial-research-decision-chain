# V0.4 E2E Iteration 02

Real PDF.js E2E Iteration 01 exposed three parser-only defects:

1. numeric text starts can sit left of the header's x coordinate;
2. wrapped labels and numeric values may occupy neighboring y rows;
3. primary-table geometry must not be reused across later document pages.

Iteration 02 changes only parser geometry handling:

- derive the label/current boundary from inter-column spacing;
- assign wrapped label rows to the nearest numeric row on the same page;
- parse primary metrics only on the detected primary-table page.

No Claims, Assumptions, Kill Criteria, Formula, Valuation or Decision rules were changed.
S-07 remains sealed.
