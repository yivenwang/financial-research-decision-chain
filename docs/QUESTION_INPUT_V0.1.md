# 问题输入层 V0.1

2026-09-16。基于 `main@667ad8b4f8209078fbda1968b44854a313f6e5a7`，关联架构评审 #18。用户已批准设计后的首批实现，并要求必要实现、验证和修复在一轮交付。

## 使用

按 README 启动应用，首页点击“进入研究问题”或访问 `/questions`。

1. 输入研究问题、演示访问码，点击“生成研究任务”。
2. 核对公司、期间、意图和所需材料，点击“确认并执行”。
3. 若缺已审核材料，返回 `MATERIALS_REQUIRED`；去 `/` 上传、审核、保存 S-05，再回来生成任务。
4. 阅读结构化事实、计算、推论、反向证据、引用和限制；接受或退回的是本次研究草稿。
5. 导出 Markdown 或完整 JSON。运行和审核分别追加保存，原研究判断和研究版本保持原样。

继续使用现有服务端变量：`MODEL_PROVIDER`、对应提供方 API Key 与模型名、`RESEARCH_DEMO_TOKEN`、可选 `RESEARCH_APP_ORIGIN`。真实密钥仅在服务端；浏览器访问码仅留在本次页面内存，不写入导出。

## 范围与模块

| 项目 | 实现 |
| --- | --- |
| 三类意图 | `CHANGE_EXPLAIN` 变化解释、`EVIDENCE_AUDIT` 证据核验、`DECISION_IMPACT` 决策影响 |
| 能力登记 | `anker-c04.v1`：安克创新 / S-05 / 2026Q1 / C-04；Source URL 和期间来自既有登记 |
| 可比期间 | 同比是 2026Q1 对 2025Q1；研究基准 V-01 / 2025 年报不作为季度同比金额 |
| 回归材料 | S-06 保留在旧隔离回归，不开放到问题层研究范围 |
| 缺材料/失败/范围外 | 分别记录 `MATERIALS_REQUIRED` / `BLOCKED` / `OUT_OF_SCOPE`，不生成替代答案 |
| 成功状态 | `ANSWER_READY` / `PARTIAL` 表示可核对草稿；证据通过不等于专业认可 |
| 正式判断 | 不提供写接口；`formalRecommendation` 保持 `null`，EG-01 / EG-02 待复核 |
| 版本 | 问题结果绑定精确研究快照；新回滚版本不继承旧答案审核 |

- `research-question.ts`：类型、规划 Schema、版本化 Prompt、能力 Gate、Evidence Resolver、解释校验、Markdown。
- `research-question.server.ts`：鉴权、来源检查、有界输入、签名任务、模型调用及运行日志。
- `research-question-storage.ts`：运行/审核追加、摘要核对、Web Locks、历史隔离。
- `question-workflow.tsx` 与 `/questions`：最小功能页面，沿用现有视觉。
- `/api/research-question`：规划与执行分开，每个请求最多一次模型调用。

规划模型只提出意图、公司、期间、指标和节点。服务端生成正式权限清单、所需 Source、输出清单和请求编号。确认时验证整个规划记录的 HMAC 及一小时有效期，防止浏览器修改任务范围；签名不鉴证审核人身份。

服务端复用 `buildMemoContext` 校验快照、重建规范引用和重跑冻结链，不信任可编辑标签或摘录。输出包含 Source、页码、PDF/快照摘要、原始值与审核值、比较值、披露同比、F-02/同比复算、Graph Diff、引用解释、反向证据、限制和审核绑定。没有空事实数组的有效结果。

设计示例中的 `CONTRACT_READY` 统一为 `CONTRACT_DRAFTED`；工作流状态与结果验证分开。既有研究版本仍由原流程保存/回滚；本阶段不把草稿接受伪装成正式投资判断更新。

## 模型与日志

新 Prompt 为 `question-contract.v1` 和 `question-explanation.v1`。旧备忘录 Prompt 不变。DeepSeek 保持 V4 Pro / low / 6,000 输出 token / 150 秒，OpenAI 保持既有 4,000 / 90 秒；没有自动重试或格式修复调用。

规划、确认执行各需用户动作。接口 `maxDuration=180`，生产部署须另核对平台时限。模型正文不允许数字、URL、HTML 或非法引用；事实与计算由程序输出。引用存在仍不证明推论正确，因此解释须人工审核。

日志记录原问题、能力配置、任务、规划原记录、输入快照、Source 定位/摘要、工具结果、计算、Gate、模型/Prompt 版本与摘要、请求/响应摘要、最终正文和失败码。只保留最终正文，不保存隐藏推理或密钥。失败与后续成功为独立运行。

确定性事实、计算和 Graph Diff 可复算；不承诺模型解释逐字重现。服务端目前不重新鉴证 PDF 字节或审核人身份；持久化仍是本机浏览器，不是机构共享审计库。
