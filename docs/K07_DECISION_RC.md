## 方案 A：首次触发即执行

保留指标与 ≤0 阈值，把定量触发改为本期首次非正即 `triggered`。首次本期非正时，估值盈利口径由扣非改为归母；改变估值金额与每股结果，差异由该样本非经常性损益决定，不能预先宣称更保守或更准确。C-04 系统信号已经是削弱，通常不变；人工 Claim 状态和正式投资结论仍需人签署。

UI 应写明“首次非正即触发”，区分系统触发、人工下调和会计专业审批。测试需要新增首次非正、零值、负值、连续非正及会计触发的完整口径断言，更新首次触发估值预期。S-05、S-06 已冻结正常样本的扣非同比为正，定量分支不受影响；其旧快照不得回写。历史首次非正样本如重新计算可能改变 K 状态和估值，须在新引擎版本追加明确对照；本轮未读取 S-07。

## 方案 B：首次观察、连续两期执行

保留当前实现。文案须由负责人批准后改为“首次非正进入观察；经核验的连续两个可比期间非正触发取消归一化；会计认定经常性立即触发”。必须定义何为连续可比期间，以及历史缺失时显示不可判断而非推定通过。

UI 应明确首次观察已经产生 C-04 削弱信号，但 K-07 尚未切换盈利口径。测试保留连续两期规则，并补首次观察的扣非口径、两期触发的归母口径、零值与断序边界。S-05、S-06 与现有历史计算结果保留；文案及版本化规则引用更新不可回写历史 Prompt/输出/审核事件。人工 Claim 状态和投资结论仍需独立审核，不能把连续两期自动等同买卖指令。

## 推荐（尚未采纳）

建议负责人评估选择 **B**：它与当前冻结实现、既有两期回归和盈利口径切换一致，能减少赛前计算语义与历史版本迁移。但它是容忍首期观察的金融政策，并非纯文案修复；若原设计要求首期立即取消，A 才忠实于该政策。推荐理由不构成批准，也不能替代专业意见。
